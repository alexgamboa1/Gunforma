# /go/<affiliate_link_id> and /go/part/<product_id> are the outbound click
# layer, not pages — the first to a partner listing, the second to a part's
# own store. Every buy anchor on the site already carries rel="nofollow"
# (partner buttons "sponsored nofollow", maker buttons "nofollow" alone), so a
# crawler should not be following these anyway — this says it in the one
# place a crawler reads before it fetches anything.
#
# It costs no SEO: /go/ URLs are in no sitemap, carry no canonical, and are
# not what the JSON-LD offers point at. product-page.mjs emits each Offer's
# `url` as the RETAILER's own URL, never the /go/ one, and maker links are
# not offers at all, so nothing structured is behind this rule. An
# unresolvable /go/ id already answers a noindex 404.
